# 세대공감 초성·음악 퀴즈

태블릿 가로 화면에 맞춘 Streamlit 앱입니다. 초성 10문제와 음악 10문제가 들어 있습니다.

## 실행

Python 3.11 이상이 설치된 PC에서 압축을 풀고 해당 폴더의 터미널에서 실행하세요.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 0.0.0.0
```

Windows는 `start_windows.bat`를 더블클릭해도 됩니다. PC와 태블릿을 같은 Wi-Fi에 연결한 뒤, 실행 화면의 Network URL(예: http://192.168.0.10:8501)을 태블릿 브라우저에서 여세요. PC 방화벽이 묻는다면 신뢰하는 개인 네트워크에서 허용하세요. PC는 행사 중 계속 켜 두어야 합니다. 태블릿만으로 Python 파일을 직접 실행하는 앱은 아닙니다.

인터넷 주소로 접속하려면 이 폴더를 본인 GitHub 저장소에 올리고 https://share.streamlit.io 에서 저장소 및 `app.py`를 선택해 배포하세요. 별도 secrets/API 키는 필요 없습니다. 이 배포는 아직 수행되지 않았습니다. 공개 저장소에는 상용 음원을 올리지 마세요. 서버에 올린 음원은 세션 메모리에서 처리합니다.

## 행사 전 준비

1. 왼쪽 메뉴 → **진행자 준비**를 엽니다.
2. 사용 가능한 음원을 각 곡에 업로드합니다. MP3, WAV, M4A, OGG, FLAC을 지원합니다.
3. 각 곡의 추천 부분을 직접 들어 보고 시작 시각(초)을 입력합니다. 기본값 0초는 추천 하이라이트 시각이 아닙니다. 원곡·리메이크·라이브마다 시간이 달라 고정 시각을 제공하지 않았습니다.
4. **10초 만들기 / 적용**을 누르고 미리 듣기로 확인합니다. 끝까지 10초가 남지 않으면 저장되지 않습니다.
5. 다른 가수의 녹음을 사용하면 정답 가수도 바꾼 뒤 적용합니다.
6. **준비한 10초 음원 ZIP 저장**으로 백업합니다. 새 세션에서는 ZIP을 올리고 **ZIP 복원하기**를 누릅니다.
7. 행사에 쓸 태블릿에서 음량, 블루투스 스피커, 10초 재생을 미리 확인하세요. 준비 화면은 참가자에게 보이지 않게 설정합니다.

상용 음원과 10초 하이라이트 파일은 포함하지 않았습니다. 사용 권한이 있는 음원을 넣어야 음악퀴즈가 작동합니다. 파일을 10초로 실제 잘라 넣으므로 전체 노래가 계속 나오는 방식이 아닙니다. WAV 22,050Hz 모노 기준 220,500프레임으로 확인합니다. FFmpeg는 imageio-ffmpeg 패키지에 포함된 실행 파일을 사용합니다.

## 게임 진행

- 초성: 큰 초성 → 필요하면 힌트 → 정답 확인 → 다음 문제.
- 음악: **노래 듣기 · 10초**를 한 번 누르면 재생, 같은 자리의 **정답 확인**을 누르면 가수와 곡명 공개.
- **10초 다시 듣기**, 이전 문제, 다음 문제 버튼도 있습니다.
- 문제를 이동하면 정답 상태가 초기화됩니다. 음악은 문제 이동으로 플레이어가 바뀌면 종료됩니다.
- 브라우저 새로고침·서버 재시작·세션 만료 시 업로드가 사라질 수 있으므로 ZIP을 저장하세요.
- 팀은 어르신·부부·아이를 섞어 구성하고, 초성은 정답 1점, 음악은 제목 1점+가수 1점으로 진행하면 좋습니다. 점수는 진행자가 별도로 기록합니다.
