# 세대공감 초성·음악 퀴즈

공개 앱: https://family-quiz-john-2026.streamlit.app/

- 초성 10문제: 영화·드라마 5개 + 속담 5개.
- 음악 10문제: 기존 곡 순서 유지. 음악은 별도 휴대폰에서 재생합니다.
- 음악퀴즈의 큰 문제 화면을 누르면 가수와 제목이 나타납니다. 다음 문제 버튼으로 이동하면 정답이 가려집니다.
- 음원 업로드와 재생 기능은 제거했습니다.
- 태블릿 가로 화면에서 왼쪽 메뉴를 닫으면 글씨가 크게 보입니다.

로컬 실행: python -m pip install -r requirements.txt 후 python -m streamlit run app.py
